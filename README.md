# MotorPH Employee Payroll System

The **MotorPH Employee Payroll System** is a CP2 project developed by MMDC students. This application helps manage employee information, attendance records, and payroll data through separate Employee and Payroll Staff interfaces.

---

# 🚀 How to Run the Application

1. Open the project in your preferred Java IDE (NetBeans is recommended).
2. Verify that all project files are in the correct folders.
3. Ensure the **CSV** folder and its files are located in the proper directory.
4. Run the **CP2MS1Grp10.java** file.
5. Log in using one of the credentials below.

# 📖 Navigating the Application

## Employee

1. Log in using the **Employee** account.
2. Enter your **Employee Number**.
3. You will be redirected to the **Employee Menu**.

From the menu, you can:
- View Employee Information
  - View your personal employee details
- View Payroll
  - View your monthly payroll records
- Logout
  - Return to the login screen

---

## Payroll Staff

1. Log in using the **Payroll Staff** account.
2. You will be redirected to the **Payroll Staff Menu**.

From the menu, you can:
- View Payroll of All Employees
  - Display payroll records for every employee
- View Payroll of a Specific Employee
  - Search payroll using an employee number
- Manage Employee Records
  - Add, edit, or delete employee information
- Manage Attendance Records
  - Add, edit, or delete attendance records
- Logout
  - Return to the login screen
